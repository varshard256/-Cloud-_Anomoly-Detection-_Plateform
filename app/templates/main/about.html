Built to catch the anomaly that a dashboard full of green numbers would miss.

NeuroCloud is an AI-based anomaly detection platform for cloud computing environments, developed as an academic major project. It simulates a fleet of cloud servers, streams realistic monitoring metrics, and applies unsupervised and supervised machine learning models — Isolation Forest, Random Forest, One-Class SVM, and Local Outlier Factor — to catch CPU spikes, memory leaks, disk saturation, and network anomalies as they happen.

Beyond detection, it predicts future resource exhaustion and server failure probability, and recommends a concrete remediation action for every anomaly it finds — closing the loop from signal to fix.

Stack
  • Flask + SQLAlchemy
  • Scikit-learn / Pandas
  • Bootstrap 5 + Chart.js
  • MySQL
